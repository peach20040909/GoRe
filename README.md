# 고리 (Go:RE)

### GO Again · REconnect — 다시 찾아가, 마음을 잇다

> 관광명소에 함께 온 사람과의 추억을 **장소를 해치지 않는 디지털 고리**에 남기고,
> **그 자리에 다시 와야** 열 수 있게 하는 위치 기반 AI 기록 서비스.

## 01. Discover — 배경 조사

**서울 대표 관광지는 이미 외국인 여행자로 붐빈다.**
- 4대 궁·종묘 외국인 입장객은 198만(2023) → 314만(2024) → 423만(2025), 전체 관람객 중 외국인 비중은 16.9% → 28.1%로 늘었다.
- 2025년 경복궁 관람객 689만 명 중 40.4%가 외국인이다. 서울을 찾은 외국인의 경복궁 방문률은 42.2%로, 조사 장소 52곳 중 공동 2위다.
- 2025년 방한 외국인은 1,894만 명으로 역대 최대다.

**여행은 둘이 온다.** 동행 인원은 2명이 46.1%로 가장 많고, 둘이 온 여행의 동행은 친구·연인(57.8%), 가족·친지(40.2%) 순이다.

**함께 남긴 기억은 재방문으로 이어진다.** 여행 중의 경험이 만족도와 기억의 생생함을 거쳐 재방문 의향으로 이어진다는 연구가 있다(고영길, 2018).

**하지만 지금의 흔적 남기기는 장소를 해친다.**

| 사례 | 내용 |
|---|---|
| 남산 사랑의 자물쇠 | 외국인 5명 중 1명(22.2%)이 찾는 N서울타워. 쌓이는 자물쇠로 환경 오염 우려 |
| 파리 퐁데자르 | 무게 문제로 자물쇠 약 45톤을 철거하고 금지. '자물쇠 대신 사진으로' #lovewithoutlocks 캠페인 |
| 안동 하회마을 | 유네스코 세계유산 마을 곳곳에서 관광객이 남긴 한글 낙서 발견 |

### 문제 제기

> **환경적 훼손을 막고, 여행자의 추억을 보존 가능한 공간의 부재**

## 02. Define — 문제 정의

### 인사이트

1. **둘이 온 여행자는 장소에 '우리'의 흔적을 남기고 싶어 한다.** 2인 여행 46.1%, 남산서울타워·퐁데자르의 사랑의 자물쇠.
2. **흔적을 남기는 지금의 방식은 장소를 해치고, 남긴 뒤엔 끝난다.** 퐁데자르 자물쇠 약 45톤 철거, 하회마을 낙서, 적고 끝나는 방명록.
3. **기억에 남는 경험과 새로움이 다시 올 이유가 된다.** 기억에 남는 경험은 재방문 의향과 관련 있고(Hosany 외, 2022), 박물관 재방문 이유 1위는 '새로운 것'이다(미국박물관협회, 2024).

### 행동 변수 · 페르소나 · 저니맵

- **행동 변수 매핑:** 미국 거주 기반 합성 페르소나 200명(NVIDIA Nemotron-Personas-USA 선별본)을 15개 행동 항목으로 비교해 세 그룹(문화·역사 탐방형, 여행 사진 기록형, 자연명소 자동차 여행형)으로 나눴다.
- **페르소나:** 클레어 밀러(32세, 미국 시애틀). 연인과 서울에 처음 온 개별 여행자.
  > "사진은 있는데, 우리가 왜 웃었는지는 기억이 안 나."
- **저니맵 (AS-IS):** 홍제폭포에서 둘이 웃는 사진을 찍는다 → 메모장에 아무렇게나 적고 이동한다 → 몇 달 뒤 사진을 다시 봐도 그날의 대화가 떠오르지 않는다 → 연인에게 사진을 보내 묻는다.
  - 니즈: 떠나기 전에 지금 있는 장소에 둘의 추억을 짧게 남기고, 다시 그곳에 갔을 때 사진만으로는 떠오르지 않는 그날의 이야기를 함께 다시 보고 싶다.

### 해결 방향

| 문제 | GO:RE에서는 |
|---|---|
| P1 남길 방법이 없음 | **장소를 해치지 않고, 그 자리에서만 남김.** 장소의 이야기를 담은 디지털 고리에 그날의 사진과 편지를 남기고, 어떤 언어로 써도 AI가 정리 |
| P2 다시 올 이유가 남지 않음 | **다시 와야 열리게 함.** 이 장소에서·함께·정한 날·다음 계절에 열리도록 잠그고, 다시 오면 AI가 그날과 오늘의 사진을 엮어 재회 리포트를 만듦 |
| P3 관광지는 누가 다시 오는지 모름 | **남긴 기억이 장소의 데이터가 됨.** 공개에 동의한 한 줄이 장소의 기억으로 쌓이고, 장소별 재방문과 방문 언어가 보임 |

모든 단계의 전제: **가입 없이 둘러보기 · 어떤 언어로든 · 1~2분 안에 남기기**

### MVP — 추억을 기록하고, 조건을 정하고, 함께 다시 방문한다

| | 기능 | 설명 |
|---|---|---|
| 01 | 추억 기록 | 관광명소에서 동행자와 찍은 사진과 그날의 이야기를 디지털 자물쇠(고리)에 담는다 |
| 02 | 해금 조건 설정 | 이 장소에서·함께·정한 날·다음 계절 중 언제 다시 열지 정한다 |
| 03 | 동행자와 함께 재방문 | 그 장소에 다시 와야 고리가 열리고, 그날의 편지와 사진을 함께 다시 본다 |

## 03. Develop — 전략과 설계

### UX 전략 키워드 — 남기는 순간부터, 다시 만나는 순간까지

| 키워드 | 니즈 | 기능 |
|---|---|---|
| **Low-friction Capture** 부담 없는 기록 | 현장에서 짧게 남기고 싶다 | 사진 한 장과 편지를 장소와 묶어 하나의 디지털 고리로 저장 |
| **Anticipatory Reveal** 기대감을 만드는 해금 | 의미 있는 시점에 다시 보고 싶다 | 기념일·계절 등 조건을 정해 다시 열 순간을 기대하게 함 |
| **Shared Reconnection** 함께하는 재연결 | 같은 사람과 같은 곳에서 회상하고 싶다 | 동행자와 같은 장소에 다시 와서 함께 추억을 열고 이어 감 |

### 비주얼 전략 키워드

**Soft Archive**(부드럽고 정돈된 기록) · **Emotional Connection**(동행의 온기) · **Gentle Reveal**(차분하지만 설레는 발견) · **Place Identity**(장소마다 다른 기억의 표정)

### 디자인 시스템 — 풍경은 다르게, 경험은 일관되게

- 중립적인 UI 위에 장소의 색과 문양을 얹는다. UI Primary `#4F63E8`, Surface `#F5F6FC`, 서체 Pretendard.
- **고리의 친구들** — 장소를 상징하는 자물쇠 캐릭터 4종. 지도 핀과 장소 목록에 쓰인다.

| 캐릭터 | 상징 | 쓰이는 장소 |
|---|---|---|
| A:RE 두근고리 | 하트 | 명지대학교 |
| NU:RE 산들고리 | 산 | 독립문 |
| SO:RE 소리 | 폭포 | 홍제폭포 |
| HAE:RE 해리 | 한복 입은 해태 | 경복궁 |

### 장소별 고리 (3D)

장소의 역사와 전통 문양을 담은 고리를 장소마다 따로 만들었다(Blender 제작, 웹·AR용 3D로 변환). 서울 문화 공간 18종이 있고, 시연 장소 4곳은 아래와 같다.

| 장소 | 고리 |
|---|---|
| 명지대학교 | 백마 자물쇠 — 명지대를 상징하는 흰 백마를 새긴 파란 자물쇠 |
| 홍제폭포 | 유리병 편지 — 코르크 마개를 열면 그날의 편지와 사진이 나옴 |
| 경복궁 | 왕실 보록 자물쇠 — 1726년 선의왕후의 옥도장을 보관하던 함의 자물쇠 |
| 독립문 | 돌 아치 고리 — 독립문의 열린 돌 아치와 안쪽의 붉은 벽돌 |

장소마다 실물 크기의 **고리 거치대** 3D 모델도 있어, AR 화면에서 캐릭터가 거치대에 고리를 걸어 준다.

### 기술 스택

| 영역 | 사용 |
|---|---|
| Framework | Next.js 15 (App Router) · TypeScript · Tailwind CSS v4 — 화면과 API를 한 프로젝트로 구성 |
| Map · AR | 네이버 지도 API(장소·핀·내 위치) · GPS(장소 좌표와 비교해 현장 방문 확인) · model-viewer(3D·AR) |
| Database | Supabase PostgreSQL(기억·장소·사용자) · Storage(사진) |
| AI | OpenAI GPT 멀티모달(`gpt-4o-mini`) — 사진과 글을 함께 이해 |
| 배포 | Vercel (`main`에 push하면 자동 배포) |

### AI가 핵심이 되는 네 가지

1. **개인화된 기억 카드 구성** — 사진과 편지를 읽고, 그날의 감정과 장소에 맞는 기억 카드(제목·각인 문구·색)를 만든다.
2. **기억 분석과 자동 분류** — 기록 유형·대상·감정·시점 단서를 정리하고, 언제 다시 열지 해금 조건을 제안한다.
3. **재방문 사진 비교와 재회 리포트** — 다시 와서 찍은 사진이 처음 사진과 같은 자리인지 판정(GPS와 함께)하고, 그날과 오늘을 잇는 재회 리포트를 쓴다.
4. **공개 기록의 익명화와 다국어** — 공개에 동의한 기록은 이름·연락처를 지운 한 줄로 바꾸고, 어떤 언어로 써도 이해한다.

AI 키가 없거나 응답이 실패해도 예시 응답으로 화면이 멈추지 않는다.

## 04. Deliver — 구현된 서비스

### 메뉴 구조 (5개 탭)

```
GO:RE
├─ 홈   지도·주변 둘러보기 → 주변 장소 목록 → 장소 상세 → 여기에 고리 걸기
├─ 추억 저장한 기억 목록 → 기억 상세·잠금 상태 → 다시 와서 열기 · 고리 삭제
├─ 고리 장소·위치 확인 → 3D 고리 미리보기 → 사진·편지 → 열람 조건 → AR 배치·저장
├─ 수집 장소별 배지 12종 → 배지 상세(획득일·획득 장소)
└─ 마이 내 추억·수집 요약 · 언어 · 계정
```

### 주요 기능

- **스플래시** — 앱 아이콘에서 두근고리가 나와 고리가 맞물리고 GO:RE 로고로 이어지는 인트로.
- **홈 지도** — 네이버 지도에 캐릭터 핀과 **내 위치(빨간 점)**. 바텀 시트로 주변 장소 목록과 장소 상세를 본다.
- **위치 기반 고리 걸기** — "여기에 고리 걸기"를 누르면 GPS로 그 장소 반경 안인지 먼저 확인한다. 다른 곳이면 **"여기는 경복궁이 아니에요! 경복궁까지 1.4km 남았어요"** 경고를 띄우고 진행하지 않는다.
- **고리 만들기** — 현장 촬영(사진 인식으로 다른 장소면 경고) → 3D 고리 미리보기 → 한지 편지지에 편지와 사진 → AI 기억 카드(만드는 동안 캐릭터 대기 화면) → 열람 조건 → AR 화면에서 캐릭터가 장소 거치대에 고리를 걸어 주는 애니메이션 → 저장.
- **추억** — 관광 카테고리 필터, 장소 그림이 들어간 '기억의 편지'. 잠긴 고리는 그 자리에 다시 와서 사진을 찍으면 AI가 같은 자리인지 판정해 열고 재회 리포트를 보여 준다.
- **고리 삭제** — 남긴 장소에서만 풀 수 있다(위치 확인. 동행 조건 고리는 동행자 확인 단계가 있으며, MVP에서는 블루투스 연동 없이 화면 흐름만 구현).
- **수집** — 장소에 고리를 남기면 그 장소의 배지를 모은다.
- **다국어** — 한국어·English·日本語·中文. 화면과 새로 만드는 AI 결과가 선택한 언어로 나온다.

## 05. Outcome — 기대 효과

### 장소가 알 수 있게 되는 것

| 장소 | 지금 알 수 있는 것 | 알 수 없는 것 |
|---|---|---|
| 경복궁 | 외국인 방문률 42.2%(52곳 중 공동 2위), 2025년 외국인 관람객 278만 명 | 다시 오는지, 무엇을 남기는지 |
| 독립문 | 외국인 방문률 1.9%(52곳 중 42위), 서대문구 장소 중 가장 높음 | 다시 오는지, 무엇을 남기는지 |
| 홍제폭포 | 외국인 누적 130만 명(서대문구 발표), 공식 조사 장소에는 없음 | 얼마나 머물고, 어디로 이어지는지 |

GO:RE에 쌓이는 기록으로 **재방문 여부**(처음 온 사람이 다시 찾아왔는가), **재방문 주기**(얼마 만에 돌아왔는가), **기록의 연결**(어떤 기억을 남긴 사람이 다시 찾아왔는가)을 볼 수 있다.

### K-콘텐츠

- **K-스토리** — 장소의 역사와 한국의 전통 문양이 고리의 형태가 된다.
- **K-소재** — 서울의 명소가 휘발되지 않고 다시 찾아올 수 있는 접점이 된다.
- **K-캐릭터** — 한국적인 요소를 더한 고리 캐릭터를 이후 더 키워 갈 수 있다.

### 제작 철학

1. **필수 API 중심의 간결한 구조** — 꼭 필요한 기능만 API로 연결해 서비스 구조를 단순하게 유지.
2. **멀티모달 AI와 지도 API 중심** — 두 축으로 기능을 구성해 외부 연동의 복잡성과 지연을 줄임.
3. **기록과 재방문 이력의 자체 축적** — 사용자의 기록과 재방문 이력을 서비스 자체 데이터로 쌓음.

## 시연 방법

서비스는 휴대폰 크기 화면 기준이다. 위치 확인이 핵심이라 **시연 모드(`?demo=1`)를 쓰지 않고 실제 GPS로** 진행한다. (시연 모드는 위치·날짜 확인을 건너뛰는 발표장용 옵션이다.)

1. 홈에서 시작 → 언어 변경 기능을 보여 준다.
2. 주변 둘러보기 → 홍제폭포·경복궁을 골라 "여기에 고리 걸기" → **위치 경고**로 위치 기반 서비스임을 보여 준다.
3. 명지대학교 → 고리 걸기: 촬영 → 3D 고리 → 편지 → AI 기억 카드 → 열람 조건("이 장소에서 열기") → AR 거치대에 고리 걸기.
4. 추억 → 기억의 편지를 열어 사진과 편지를 본다.
5. 수집 → 장소별 배지.
6. 방금 건 고리를 같은 자리에서 다시 찍어 열고, AI 재회 리포트를 본다.

## 개발

### 실행

```bash
npm install
cp .env.example .env.local   # 값 채우기
npm run dev
```

http://localhost:3000 에서 확인한다. 필요한 값은 [`.env.example`](.env.example)에 설명돼 있다(OpenAI, Supabase, 네이버 지도 Client ID 등). 키가 없으면 AI는 예시 응답으로 동작한다. DB는 Supabase SQL Editor에서 [`supabase/schema.sql`](supabase/schema.sql)과 `supabase/migrations/`를 실행하면 만들어진다.

### 구조

```
src/
  app/            화면 (홈, gori/[slug] 고리 만들기, memories 추억, collection 수집, my 마이, login)

  components/     지도(NaverMap), 3D·AR(ModelViewer), 카메라, 편지(MemoryLetter), 스플래시 등

  goris/          고리 이미지·3D 모델 · stands/ 장소별 거치대 3D · ds/ 디자인 시스템 아이콘·캐릭터
```
